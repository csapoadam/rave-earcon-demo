The arrows reorder the family. Moving an earcon up or down changes no sound, so nothing is re-measured: the measurements, the gains and the recorded buffers move with it. The z values can be typed in directly. That is the same edit a committed traverse makes — the working family changes and the decomposition is rebuilt from it — so the spiral carries on from the coordinates you typed, and only that earcon is re-measured.

Click a row to choose which earcon the spiral tunes, or "whole family" to move all ten together. The traverse advances the core tensor mix and that earcon's tuning weight at the same time, so it follows a spiral: broadly along the principal component, deviating as it goes. Sensitivity is in family widths per turn, so 1.0 means one full turn moves the earcon by about the family's own spread.

Moving the traverse previews. Releasing it commits, and the family becomes the new origin, so the traverse recentres on zero. A per-earcon edit re-renders only that earcon, about 0.8 s; a whole-family move or an envelope change re-renders all ten, about 3 s. Nothing is auditioned before it is measured, because the level a set of latents produces cannot be predicted from them.

Each earcon is recorded once when it is measured, and played back from that recording. The model emits a continuously varying texture even at a fixed latent, so gating it live gave a different sound every time. Playing the recording means every repetition is identical, and what you hear is bit-for-bit what was measured.
